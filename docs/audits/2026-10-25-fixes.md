## Boundaries

The two evidence/case databases do not become atomic. Failed unpublished requests
remain retryable using the original note; saved replies reconcile when storage is
available again. Live harness/key state is process-local and cannot be restored by
durable attachment rows. Model action validation remains lexical; it does not prove
arbitrary prose true. Synthetic evidence remains explicitly synthetic.
